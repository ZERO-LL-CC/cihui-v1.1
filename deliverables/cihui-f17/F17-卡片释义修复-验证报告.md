# F17 梗句背单词 · 卡片背面无中文 修复说明与验证报告

> 版本：v1　日期：2026-10-20　范围：`cihui-harmony/Cihui` F17 梗句导入与背诵
> 触发反馈：「少了功能，匹配中文没有匹配吖。你只有英文怎么看这个卡片背面根本没有东西」

---

## 1. 问题现象

真机导入梗句「破防了家人们谁懂啊」→ 英文 `I'm utterly shattered. Who else gets this?` → 导入成功进背诵页，
**卡片翻面后只有一行「（本词暂无释义，结合原句语境理解）」**，没有中文；确认页也只列英文单词。

## 2. 根因（三个叠加，缺一不可）

| # | 层 | 根因 | 证据 |
|---|---|---|---|
| R1 | 代码 | `MemeCore.createMemeImport` 建新词时**硬编码** `meanings: []`、`missingMeaning: true`，从不查离线词典 | `MemeCore.ts:269-279`（修改前） |
| R2 | 数据 | 随包词典 `ecdict-lite.json` 覆盖率不足：`shattered / gets / executed / done / nailed / hooked / overly / utterly / embarrassment` 全查不到，只有原形 | 逐词核对 ECDICT |
| R3 | 数据排序 | 生成脚本把「没有频次数据」当成最高频（`8000 - min(bnc,frq)`，缺失记 0），把 `utterly` 这类真实常用词挤出 CAP，反而塞进大量冷僻词 | `generate_lite_dict.py` v1 打分函数 |
| R4 | UI | `CardStack` 用 `this.CardFace(this.queue[0], x)` 直接传值，判词出队后 **@Builder 不重建**，卡片会停在上一词（真机：第 2/4 词仍显示 shattered） | `MemeReviewPage.tsx:797`（修改前） |

> R2 的深层原因：词典只收原形，而梗句英文大量是过去式/分词/三单/比较级。只「加一次查词典」修不好。

## 3. 改动清单

### 3.1 词典数据（`_ecdict/generate_lite_dict.py` → `rawfile/dict/ecdict-lite.json`）

1. **排序口径修正**：非考纲词一律按真实词频 `min(BNC, COCA)` 升序保留（无频次数据的排最后），不再用「缺失=最常用」的错误打分。
2. **新增词形索引 `alias`**：解析 ECDICT 的 `exchange` 字段（`p` 过去式 / `d` 过去分词 / `i` 现在分词 / `3` 三单 / `r` 比较级 / `t` 最高级 / `s` 复数），
   把派生形映射到原形，**不重复存释义**。
3. 词条只收单 token（带空格的短语永远匹配不到拆词结果，白占体积）。

| 指标 | v1 | v2 |
|---|---|---|
| 原形词条 | 36,000 | 36,000（不变） |
| 词形索引 | 0 | 28,057 |
| 文件体积 | 2.61 MB | **3.57 MB**（+0.96 MB） |
| 考纲词覆盖 | 7413/7413 | 7413/7413 |
| 本次真机 5 词覆盖 | 0/5 | **4/4**（`i'm` 已按停用词过滤） |

### 3.2 新增 `model/LemmaCore.ts`（纯逻辑，可 Node 单测）

规则化词形还原，作为「索引没覆盖到」的第二道兜底：
`-s/-es/-ies/-ves`、`-ed/-ied`（含 +e、去双写）、`-ing`、`-er/-est`、`-ly`、`-ment`、`-ness`、`-ily`，
外加约 90 条不规则表（`done→do`、`children→child`、`better→good`…）。
接口：`lemmaCandidates(word): string[]`（有序候选，最可能在前）。

### 3.3 `service/LocalDictService.ets`

- 加载 `alias` 索引（只存 `key→原形字符串`，不复制释义对象）。
- 新增 `lookupDetail(word)`：**L1 直接命中 → L2 词形索引 → L3 规则还原**，返回
  `{ phonetic, meaning, matchedWord, viaLemma }`，UI 可提示「变形自 get」。
- `lookup()` 签名与语义保持不变（拍照 OCR 链路零影响）。

### 3.4 `model/MemeCore.ts`

- `MemeCandidate` 新增可选 `phonetic / meaning / lemma`（由页面层查词典填充，保持纯逻辑可测）。
- `createMemeImport`：
  - 新词按候选写入 `phonetic` / `meanings`，`missingMeaning` 由 `meanings.length === 0` 决定；
  - 已有词若释义为空、且候选查到了释义，**顺手补齐**（老数据自愈），不覆盖用户手填。
- 停用词扩充：`i'm / i've / it's / don't / can't / gonna …` 及**通用缩写兜底**
  （撇号前半段是停用词或单字母 → 整词丢弃），不再依赖清单是否列全。

### 3.5 `pages/meme/MemeImportPage.ets`

- 进页面预加载词典；「拆词 →」改为异步：**先匹配中文再进确认页**（按钮文案「匹配中文…」）。
- 已在词库里的词优先用词库释义（用户手填的不会被词典覆盖）。
- 确认页每行改为两行：`英文 + 音标` / `中文释义`（未收录显示「暂无释义，背诵时看原句语境」，变形显示「释义见原形 get：…」）。
- 汇总条新增「有释义 4/4」。
- 勾选/取消与「再背一遍强化」复制候选时**一并带走音标/释义/原形**（否则一勾就又空了）。

### 3.6 `pages/meme/MemeReviewPage.ets`

- 卡片背面：有释义直接显示；变形词补一行「变形自 get」；**没释义时直接把中文原句端出来**（不再是空白 + 一个按钮）。
- 修复 R4：卡片区改 `ForEach(this.queue.slice(0,1), …, key = wordId)`，出队后强制重建。
- 老数据补释义**只补内存展示、不回写词库**（见 §7 已知问题）。

### 5.1 R-07 复验：卡片切换（`ForEach + wordId` 是否生效）

| 3 | 第 3 / 5 词 | `little` /ˈlitl/ | ✅ 变了 |

- 4 次连续切换全部正确，**未复现「停在上一个词」**；
- 每次切换后卡片自动回到**英文面**（翻面状态随节点重建复位），符合预期；
- 第 4 词翻面实测：`scared /skeәd/` → **`a. 害怕的, 担惊受怕的, 惊慌的, 吓坏了的`**（截图 `09`）；
