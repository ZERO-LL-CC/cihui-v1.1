## 2. 需求分析

### 2.1 功能列表

| 序号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| F-01 | 中文原句输入 | P0 | 多行文本，用于后续翻译与「看原句」 |
| F-02 | 离线翻译触发 | P0 | 点击「离线翻译」，端侧同步出结果，无网络请求 |
| F-03 | L1 整句库匹配 | P0 | 10 条预设梗句，归一化后精确匹配，直出地道英文 |
| F-04 | L2 梗词改写与拼句 | P0 | 32 条梗表，长词优先替换，按句号拼装英文短句 |
| F-05 | L3 未命中降级 | P0 | 不产出英文，提示手填，**不得编造** |
| F-06 | 梗味命中建议区 | P1 | 展示未进英文框的梗：梗词→标准中文→英文俚语 |
| F-07 | 拆词三态确认 | P0 | 已掌握（绿）/学习中（黄）/新词（蓝），可勾选、左滑删除 |
| F-08 | 防错拦截 | P0 | 占位符未清、可背词 <2 均不得进入确认步骤 |
| F-09 | 导入并开始背诵 | P0 | 单次事务落库，跳转梗句背诵页 |

### 2.2 业务规则

| 规则ID | 规则描述 | 对应功能 |
|---|---|---|
| BR-01 | L1 匹配前做归一化：只保留汉字/字母/数字，标点、空白、引号、括号全部剥离 | F-03 |
| BR-02 | L2 按梗词长度降序匹配，保证「破大防」不被「破防了」截断 | F-04 |
| BR-03 | 梗表拉丁条目大小写不敏感（`YYDS`/`Yyds`/`yyds` 等价） | F-04 |
| BR-04 | 英文脚手架中未命中片段用 `[...]` 占位；占位符后接空格，不接句号 | F-04 |
| BR-05 | 英文框含 `[...]` 时禁止拆词 | F-08 |
| BR-06 | 拆词结果 <2 个可背词时禁止进入确认页 | F-08 |
| BR-07 | 全链路零网络请求、零 API Key、零模型文件 | F-02 |
| BR-08 | 已掌握词默认不勾选且置灰；「再背一遍强化」可解锁 | F-07 |
| BR-09 | 至少保留 2 个有效词才能导入 | F-09 |

### 2.3 风险分析

| 风险ID | 风险描述 | 等级 | 应对措施 |
|---|---|---|---|
| R-01 | `STOP_WORDS` 被人为加词，导致 L1「这波操作太细了」拆词从 2 跌到 1，被 BR-06 拦截 | 高 | 该句仅 `move, executed` 两词，零冗余；建议加回归断言锁住「10 条整句库拆词均 ≥2」 |
| R-02 | 多梗拼句是「梗的英文对照」而非自然译文，用户可能误认为翻译质量差 | 中 | 保留 `needsManual` + Toast 提示润色；产品文案需说明能力边界 |
| R-03 | `i'm` / `don't` / `it's` 等缩略形式不在停用词表，会被当作待背单词 | 中 | `MemeCore` 原有行为，本次按「拆词算法保留」要求未改 |
| R-04 | 「梗味命中」区在多梗/单梗场景被 `pendingHits` 过滤为 0 行，等同死 UI | 低 | 建议改为纯展示不可点 |
| R-05 | 整句库仅 10 条、梗表仅 32 条，表外表达一律 L3 留空 | 中 | 按用户反馈持续扩充词表 |
