动效处方

问题不在「动效少」，在于没有编排：现在是每个组件各自 200ms 淡入，缺少先后与节奏。改成一条时间轴，成本很低但观感差一档。

入场序列
顶栏 → 进度 → 卡片（上浮 16px + blur 6→0）→ 释义（逐行 stagger 40ms）→ 底部按钮
0/60/140/260/320ms
卡片切换
水平位移 28px + scale .96，阴影收放；连点用 spring 阻尼，不做纯 ease
380ms spring
数字滚轮
旧值上滑出、新值下滑入，等宽数字防抖
380ms
进度填充
不要 linear，用轻弹簧，尾部略过冲再回落
500ms .16,1,.3,1
发音反馈
按钮 scale .94 + 三道声波扩散，声波与真实音频同步
600ms
降级
reducedMotion 下全部换 120ms opacity，位移与 blur 归零
120ms

有品味的设计网站

按用途分组，都是我平时真会翻的。做移动端 UI 时优先看 Mobbin / Refero，看真实产品怎么排版，比看概念稿有用得多。

移动端 / 真实产品截图
Mobbin ↗
十万级真实 App 流程截图，按功能筛选，做移动端最有用的一站
Refero ↗
按页面类型检索真实产品 UI，覆盖主流 App，细节能看到像素级
Screenlane ↗
按交互模式归类，适合找「进度条 / 卡片切换」这类具体组件
Pttrns ↗
老站点但干净，iOS 交互模式库，付费墙多但预览够用
整体品味 / 站点气质
Godly ↗
策展级别极高，看的是「有主张的设计」，不追流行
SiteInspire ↗
按风格和类型过滤，克制冷淡一类的样本最齐全
Minimal Gallery ↗
极简方向的纯样本库，排版与留白参考
Savee ↗
设计师的图片书签站，视觉密度高，适合刷灵感
