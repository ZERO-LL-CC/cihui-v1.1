🔍 单词流水追踪 — 每个词在计划表里怎么流动

每行一个词（编号 = 词#1、词#2…），横轴是天。带 📷 的是拍照导入的词。点某个词的编号，下方显示它的逐日事件明细。 新首学 复复习·认识 复模糊 复不认识 ★掌握毕业 休缺席日
模拟规则说明（点开查看公平性设计） 1. 记忆底模（对两种算法一视同仁）：每个词的"真实记忆状态"用 FSRS 状态方程维护——记忆强度 S、难度 D 随每次复习按官方公式演化（含难度线性阻尼与均值回归、遗忘后稳定性公式）。这是模拟里的"客观记忆规律"。
2. 判定生成：复习时先按真实经过天数算出记忆留存率 R（遗忘曲线），取 R 的画像指数次幂（学霸 ^0.6 / 普通 ^1.0 / 学渣 ^1.6）得到实际命中率；掷随机数：命中 → 认识；未命中 → 按画像"补认率"（学霸 0.5 / 普通 0.4 / 学渣 0.3）分摊为模糊/不认识。新词首测无记忆记录，按画像固定概率（学霸 75/20/5、普通 50/30/20、学渣 25/35/40）。
3. 两种算法的唯一差别：什么时候安排复习。甲永远按首学后第 1/2/4/7/15 天；乙按每个词自己的 S 值算出"留存率降到 90%"的那一天。判定与记忆更新完全同模。
4. 甲的语义细节（与词慧 App 一致）：认识 → 推进节点且不早于明天；模糊 → 停留当前节点 + 次日强制复习；不认识 → 节点清零、次日按新词重学；R15 通过 → 掌握毕业。
5. 已知口径差异：乙的"掌握"用 S≥21 天近似（App 融入时可改为具体阈值策略）；模拟按天粒度，忽略 App 内的同日短时步骤；FSRS 移植为 FSRS-6.0 公式（21 参数默认权重、目标留存率 0.9、无 fuzz）。
6. 随机源：mulberry32 固定种子，参数不变时每次模拟结果可复现。
7. 分流规则（词怎么流通）：甲——新词首测认识 → R1（第2天）；之后每个节点命中才推进 R1→R2→R4→R7→R15（对应首学后第 1/2/4/7/15 天，跨节点按首学日+offset 对齐）；中途模糊 → 停留当前节点、次日强制复习；不认识 → 节点清零、次日当新词重学（学习记录归零）；R15 命中 → 掌握毕业，等价于"复习连续命中 5 次且中途从没清零"。乙——每次判定后按公式更新记忆强度 S，下次复习日 = 留存率降到 90% 的那天；S≥21 天即真实掌握，但不毕业，继续按 FSRS 排期巩固。
8. 拍照导入两种模式（与词慧 App 语义一致）：「加入当天计划」= 导入日立刻首学，不占每日新词配额（用户主动行为）；「直接加入词本」= 进新学队列，从导入日起找第一个有配额空位的天插入，队列满则自动顺延到队尾（planNewWords 的真实行为）。
9. 缺席日与打散：缺席日整休，学习/复习都不进行，但记忆照常衰减，所有任务顺延堆积到回来的那天；勾选「打散」后，逾期复习每天只摊还约 1/3（老的先复习），当天的任务照常，避免回来第一天被几百个逾期词劝退。
