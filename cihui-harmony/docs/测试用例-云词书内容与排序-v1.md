- **测试类型**：功能测试 + 数据正确性测试 + 真机 UI 验证

## 2. 需求分析

### 2.1 功能列表

| 序号 | 功能点 | 优先级 | 说明 |
|------|--------|--------|------|
| 1 | 五本词书内容互不相同 | P0 | cet4 / cet6 / kaoyan / gaokao / zhongkao 词集必须各为独立集合 |
| 2 | 词书词序有教学意义 | P0 | 不得按字母序导出，否则每本首词都是 abandon |
| 3 | 详情页预览体现词书全貌 | P0 | 预览 12 词应分散取样，不得只截开头 |
| 4 | 导入后落库顺序与文件一致 | P0 | App 端不得二次排序，否则生成端改动无效 |
| 5 | 导入幂等与词本切换 | P1 | 同一 cloudBookId 不可重复导入；导入即切换背诵词本 |
| 6 | 词表页展示与落库一致 | P1 | BookWordsPage 显示顺序 = data.json 中该 bookId 的顺序 |

### 2.2 业务规则

| 规则ID | 规则描述 | 对应功能 |
|--------|----------|----------|
| BR-01 | 级别链固定为 zk ⊂ gk ⊂ cet4 ⊂ cet6 ⊂ ky（近似包含关系） | 词序生成 |
| BR-02 | 排序键 = (是否本文独有词, 是否超高频功能词, frq, 词) | 词序生成 |
| BR-03 | 「本文独有词」= 不在任何更低级词书中的词，排在前段 | 词序生成 |
| BR-04 | frq ≤ 100 的功能词（the/be/and/of…）后置到所在段末尾 | 词序生成 |
| BR-05 | 预览 12 词 = 全量上等距取样（首/中/尾），非前 12 个 | 预览 |
| BR-06 | 导入按 json 数组顺序逐条写入，不排序、不去重 | 导入落库 |
| BR-07 | 同一 cloudBookId 已存在则抛「该词书已导入，请勿重复下载」 | 导入 |

### 2.3 风险分析

| 风险ID | 风险描述 | 风险等级 | 应对措施 |
|--------|----------|----------|----------|
| R-01 | 重排时丢词/重复（buckets 去重逻辑被破坏） | 高 | 改前后逐本比对 set 相等 + 长度相等 |
| R-02 | 功能词后置误伤实义词（frq 缺失词被当 999999） | 中 | frq 缺失统一排段末，不参与功能词判定 |
| R-03 | App 端二次排序导致生成端改动无效 | 高 | grep 全链路无 sort；真机读 data.json 验证 |
| R-04 | 已导入用户拿不到新顺序，误判为未修复 | 高 | 交付说明明确「需重新导入」；用例覆盖该场景 |
| R-05 | 预览分散取样导致搜索命中率下降 | 低 | 搜索仍匹配书名/版本/年级，预览词仅辅助 |
| R-06 | 单词语批次（length=1）触发取样越界 | 中 | spread_sample 对 len<=n 直接返回全量 |

## 8. 遗留与建议

1. **已导入用户无法自动获得新顺序**：需要「删除词本 → 重新导入」。若要免手动，可加一次性迁移（检测词本词序是否为字母序后重排），但要评估对已有学习进度的影响。
2. **TC-311 / TC-313 未真机复测**：本轮为保护用户数据，导入验证后已恢复备份，重复导入与取消导入的路径待补测。
3. **`_ecdict/ecdict.csv`（63MB）未入库**：`generate_books.py` 依赖它，换机后重跑生成需先下载 ECDICT。
