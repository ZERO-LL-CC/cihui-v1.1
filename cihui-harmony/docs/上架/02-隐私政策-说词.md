## 说词 隐私政策

生效日期：2026年11月5日

「说词」（包名 com.cihui.word）是一款背单词应用，开发者张俞蔚。这个应用的核心功能基本都在你的手机本地完成，我们尽量少碰你的数据。下面如实说明。

### 一、我们用到的权限和用途

**相机**：你主动点「拍照导入词表」或「拍照识词」时才申请。拍的照片只在手机本地做文字识别，识别完不上传、不保存原图。

**麦克风**：你用「语音快过」时申请——对着手机说出单词的中文意思，应用在本地离线判断你认不认识。录音不上传，也不保存。

**提醒**：你开启每日打卡提醒后，应用调用系统提醒能力定时提醒你复习，应用不运行时也能响。随时可以在设置里关掉。

**振动**：下拉刷新、复习翻卡时的一点轻震动反馈，可在设置里关，不收集任何信息。

**网络**：说词**没有申请网络权限**，整个应用完全离线运行——不联网、不上传、不产生任何网络请求。手机设置里「应用 → 说词 → 流量使用情况」会显示 0。

### 二、数据存在哪

学习记录、词书、打卡、例句收藏，全部存在你的手机本地，我们拿不到，也不会上传到任何服务器。应用没有账号体系，无需登录或注册即可使用全部功能。

### 三、例句从哪来

页面里的例句是在应用打包时**一次性预置**进安装包的，阅读时直接读本地文件，不联网、不请求任何服务：

- 真人例句：来自开放语料库 **Tatoeba**（CC BY 2.0 FR 许可，允许免费使用，需署名）。
- 少数生僻词没有合适例句的，由人工编写补充并校对，同样打包进安装包。

这个过程中**不涉及你的任何数据**：没有任何单词、没有学习记录被发送出去，因为应用自身没有联网能力。

### 四、你的权利

- 权限：系统「设置 → 应用 → 说词 → 权限」里随时开或关。
- 数据：系统「设置 → 应用 → 说词 → 存储」里清除数据，即可删掉全部本地记录。
- 其他：对数据处理有疑问，联系下方邮箱。

### 五、儿童隐私

本应用是学习工具，不面向未满 14 周岁的儿童提供定向服务，也不会主动收集儿童的个人信息。如监护人发现儿童在使用本应用时提交了个人信息，可通过下方邮箱联系我们处理。

### 六、本政策的更新

政策有大的改动，会在应用内或本页面提示。
