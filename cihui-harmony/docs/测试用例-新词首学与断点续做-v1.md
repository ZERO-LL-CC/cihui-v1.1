# 测试用例集 · 新词首学（F7/F8）状态流转与断点续做

## 1. 基本信息

- **项目名称**：词慧 App（HarmonyOS 首发）
- **模块名称**：F7 新词首学浏览 / F8 语音快过 / 今日任务入口路由
- **测试类型**：功能测试 + 状态流转测试 + 真机端到端测试
- **设备**：畅享 90（HarmonyOS，1080×2406）
- **设计日期**：2026-10-20
- **本轮触发缺陷**：用户反馈「学完了状态没有更新，页面还跳转首次」

## 2. 需求分析

### 2.1 功能列表

| 序号 | 功能点 | 优先级 | 说明 |
|------|--------|--------|------|
| F-01 | 今日新词入口路由 | P0 | 首页按钮 / 新词桶 / 打卡页「去完成」三处入口口径一致 |
| F-02 | F7 浏览进度续做 | P0 | 退出后重进接着上次那张词卡看 |
| F-03 | F8 判定进度续做 | P0 | 退出后重进接着上次那个词判，已判词不重考 |
| F-04 | 本轮确认落调度 | P0 | 确认后 `stage` 由 NEW 推进到 R1、`dueDay` 推到次日 |
| F-05 | 确认后草稿清理 | P1 | 落调度同时清 F8 / 浏览两份草稿，下一批重新开始 |
| F-06 | 学完首页状态同步 | P0 | 首页进度、新词桶、打卡门禁同源刷新 |

### 2.2 业务规则

| 规则ID | 规则描述 | 对应功能 |
|--------|----------|----------|
| BR-01 | 只有浏览到末张（`reachedEnd=true`）才允许进 F8 | F-02 |
| BR-02 | 判「认识」→ `stage=R1`、`firstLearnDay=当天`、`dueDay=次日`、`status=LEARNING` | F-04 |
| BR-03 | 判「不认识」→ `stage=NEW`、`status=WRONG`、`dueDay=次日`、`firstLearnDay=''`（次日重新首学） | F-04 |
| BR-04 | 判「模糊」→ 停留当前节点、`roundRequeue=true`、`forceNextDay=true`、`dueDay=次日` | F-04 |
| BR-05 | 判定在点「确认」前只存页面内存 + 草稿，不改调度 | F-03/F-04 |
| BR-06 | 草稿按天作废，跨天不再续 | F-02/F-03 |
| BR-07 | 入口跳转必须同时校验「已浏览完」+「本批词序一致」，换批/换天不得错位 | F-01 |
| BR-08 | 确认落库后清空草稿，下一批从第 1 张重新开始 | F-05 |

### 2.3 风险分析

| 风险ID | 风险描述 | 风险等级 | 应对措施 |
|--------|----------|----------|----------|
| R-01 | 入口只看「有没有新词」，不看「是否已浏览完」→ 用户被打回第一张 | 高 | 新增 `StudyEntry.isTodayBatchBrowsed()` 统一判定 |
| R-02 | 草稿跨天串批，把昨天的判定套到今天的新词上 | 高 | 草稿带 `day` + 按词序逐项比对 |
| R-03 | 确认按钮被内容挤出安全区，点不动 | 高 | 按钮固定在 Scroll 外 + `safeAreaPadding`（上轮 D-2 已修） |
| R-04 | 确认后落点漂移到打卡/我的页，用户以为没学 | 中 | 本轮实测确认后 1–4s 稳定在首页 |

## 5. 状态转换

### 5.1 调度状态

| 状态ID | 名称 | 描述 |
|--------|------|------|
| S1 | NEW/LEARNING | 今日待首学，`dueDay=当天` |
| S2 | R1/LEARNING | 首学通过，次日 R1 复习 |
| S3 | NEW/WRONG | 判不认识，次日重新首学 |
| S4 | NEW/LEARNING + forceNextDay | 判模糊，次日强制复习 |

### 5.2 转换矩阵

| 当前 | 事件 | 条件 | 动作 | 目标 |
|------|------|------|------|------|
| S1 | 首过判认识 | phase=FIRST | `stage=R1`、`dueDay=+1` | S2 |
| S1 | 判不认识 | — | `status=WRONG`、`dueDay=+1`、`firstLearnDay=''` | S3 |
| S1 | 判模糊 | — | `forceNextDay=true`、`roundRequeue=true`、`dueDay=+1` | S4 |
| S3 | 次日首过 | phase=FIRST | `stage=R1` | S2 |
| S4 | 次日复习认识 | phase=REVIEW | 清 `forceNextDay`、节点推进 | S2 |

| 缺陷 | 现象 | 根因 | 修复 | 验证 |
